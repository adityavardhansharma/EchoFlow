EchoFlow bundles a native document parser (anydoc) as libanydoc.so, plus the
Rust crates statically linked into that library. This file is the MIT/Apache-2.0
notice set for that binary. Crate versions come from the lockfile used to
build the shipped .so (native/anydoc-android/Cargo.lock).

Re-generate when libanydoc.so is rebuilt:
  list [[package]] name+version from that Cargo.lock into this crate inventory.
