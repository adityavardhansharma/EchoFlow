# Bundled offline report rendering

- marked 15.0.12: https://github.com/markedjs/marked/tree/v15.0.12 — MIT; see marked-LICENSE.md.
- KaTeX 0.16.22, auto-render and WOFF2 fonts: https://github.com/KaTeX/KaTeX/tree/v0.16.22 — MIT; see katex-LICENSE.

The distribution JavaScript and stylesheet were obtained from jsDelivr's npm packages at these exact versions. Font URLs in the KaTeX stylesheet are embedded as data URLs so printing works without network requests.
